# 一、静水2008 问答记录提炼

> 原文：<https://panhaoneo.github.io/posts/jingshui2008/>（知乎作者「静水2008」问答合集，博客转载）
> 本文只做结构化提炼，不复述原文全篇。

## 1. 一句话方法论

原文反复用几乎相同的措辞重复了十余次，这句话就是整套方法的全部：

> **找到当下时代景气行业中最核心受益的 α，在它回调时分仓分批买入；对了死拿，错了砍掉。**

其余所有回答都是这句话的注解、前提或反例。

## 2. 五条被反复强调的原则

| # | 原则 | 原文依据（要点转述） |
|---|---|---|
| 1 | **当下** | 只回答"此刻哪个行业最景气"，不预判拐点、不猜复苏、不抄底低位行业。作者点名：预判科技见顶而去抄底白酒医药的人，被 AI 行业虹吸资金，"不但赚不到时代变革的红利，还被旧势力裹挟着泥沙俱下"。 |
| 2 | **跟随** | "好公司从来不是你选出来的，而是市场选出来的，你只需要跟随。"承认市场资金合力比自己聪明，减少主观分析。趋势识别方法被压缩成一句：**股价创历史新高**。 |
| 3 | **分仓分批** | "真正做投资的，根本不去重仓，因为轻仓一样可以达到重仓一般的收益，但风险被有效降低。"举了朋友 2000 万本金满融单吊药明康德爆仓的案例，教训两条：不加杠杆、不单吊。 |
| 4 | **止损不止盈** | 买入必须预设止损位，到点无条件砍。盈利端相反：以"不卖"的心态持有，"想着卖就一定会卖飞"。散户失败的典型形态恰好是反的——亏了死拿，赚一点就跑。 |
| 5 | **只做趋势** | 明确否定另外两条路：超短线≈赌博；纯价值投资对散户认知要求过高（需同时具备"辨认优质资产 / 科学估值 / 捕捉拐点"三项能力）。趋势投资的价值在于**屏蔽散户的弱项**（分析弱、执行弱），只需要"看见"。 |

## 3. 选股的三个可操作问句

原文给的实操路径（"第三步"）本质是每天问自己三句话：

1. 当下这个市场，**哪个行业**业绩在批量超预期、社会讨论度最高、政策明显倾斜、且行业指数已创新高？
2. 这个行业里，**哪家公司**业绩最好、涨幅最大、最被市场资金认可（即 α）？
3. 它现在**是否在回调**，回调到哪里可以分批介入？

对应到"好股票的两个显著特征"：

- **业绩好**：业绩不断刷新历史新高、不断超预期、持续稳定上涨。
- **市场认**：股价不断刷新历史新高、持续稳定上涨。

两条同时成立，才是标的。

## 4. 作者自陈的三个弯路（反面清单）

来自"交易生涯最大弯路"一问，作者转述其同行的三条：

1. **过于喜欢预判** → 跟踪信息、主观判断，导致过早止盈、卖飞成长股。
2. **特别喜欢挖掘** → 想在行业大底预判反转。但行业拐点连专业研究员正确率都极低，且行业反转与股价反应经常不同步。
3. **特别喜欢重仓** → 分仓的收益率并不比重仓差，却能睡好觉并显著降低风险。

## 5. 与本框架直接相关的两条硬约束

- **不加杠杆**（爆仓案例的第一条教训）。
- **不单吊**（第二条教训）；配合"分仓分批"，形成组合上限与单票上限。

## 6. 需要明确剥离的部分

原文包含大量非方法论内容：人生态度、情绪管理、对散户和特定人群的贬低性评价、以及"a9/a10""没有难度""一定能财富自由"这类结果承诺。这些**不进入框架**，理由：

- 结果承诺无法被规则化，也无法被回测。
- 原文自身承认样本是单一个体经验（"我就是这样过来的"），存在幸存者偏差。
- 框架只吸收可被数据检验的部分：**景气度、α 识别、回调买点、分仓、止损、持盈**。

## 7. 作者自己推荐的书单顺序

原文"大学生对自己最好的低成本投资"一问给出的阶梯，实操层第一本即本项目的第二个信息源：

1. 认知层：《穷爸爸富爸爸》《小狗钱钱》《纳瓦尔宝典》→《原则》《穷查理宝典》
2. **实操层：《笑傲股市》《股票魔法师》《100 倍超级强势股》**
3. 之后再广泛阅读成长股/价值股书籍，组成自己的投资拼图

这解释了为什么本项目把《笑傲股市》与问答记录放在一起蒸馏：**问答记录给的是原则和纪律，《笑傲股市》给的是把原则变成数字门槛的方法。**
